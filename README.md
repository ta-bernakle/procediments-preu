# 📄 README — Readaptació de procediments
## (Guia per readaptar procediments antics al sistema actual)

---

## 1. OBJECTIU

Eliminar el factor de click i substituir-lo per:
- Cost directe
- Cost estructural
- Cost fix
- Marge base
- Ajust de valor afegit

---

## 2. QUAN READAPTAR

Senyal que un procediment necessita readaptació:
- Té factor de click (×4, ×6, ×10, ×16…)
- Té marge fix arbitrari
- Té costos inflats per prudència
- No distingeix cost directe de cost estructural
- No té en compte volum ni valor afegit

---

## 3. PASSOS

1. Llegir el procediment antic
2. Identificar costos directes
3. Identificar costos fixos
4. Eliminar el factor de click
5. Aplicar el cost estructural
6. Aplicar el marge base i l'ajust
7. Calcular el preu final
8. Validar amb el mercat
9. Documentar el procediment nou
10. Versionar i desar

---

## 4. FÓRMULA

Preu venda = (Cost directe + Cost estructural + Cost fix) × (1 + Marge final)

Marge final = Marge base × Ajust de valor afegit

---

## 5. EXEMPLE DE REFERÈNCIA

Procediment antic: 10.000 flyers A6 B/N 1 cara

Càlcul antic:
- Material: 25,20 €
- Impressió (×8): 30,61 €
- Preimpressió: 8,27 €
- Guillotinat: 13,95 €
- Empaquetat: 6,50 €
- COST BASE: 84,53 €
- Marge 50 %: 42,27 €
- PREU VENDA: 126,80 €

Càlcul readaptat:
- Cost directe: 29,03 €
- Cost estructural (26 %): 7,55 €
- Cost fix: 28,72 €
- Cost total: 65,30 €
- Marge (40 %): 26,12 €
- PREU VENDA: 91,42 €
